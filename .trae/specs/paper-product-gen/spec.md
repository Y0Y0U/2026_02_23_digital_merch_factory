# 纸制品生成模块设计文档 (Paper Product Generation Spec)

## 背景 (Why)

用户需要一种独立于现有亚克力生成流程的方式来生成3D纸制品（如明信片、海报、色纸、异形卡片）。现有的亚克力生成器强制使用特定的厚度、底座和插脚逻辑，这些并不适用于纸制品。

## 变更内容 (What Changes)

* **新模块**: 独立的 `paper_generation` 模块。

* **新属性**: 用于纸品特定设置的 `PaperProperties` 类。

* **新界面**: 侧边栏中独立的“纸品”面板。

* **重构**: 更新 `core/image_processing.py`，使其可供亚克力和纸品模块复用（解耦 `acrylic_props`）。

## 影响范围 (Impact)

* **受影响的规范**: 无直接影响，但增加了新能力。

* **受影响的代码**:

  * `core/image_processing.py`: 重构为接受参数而非读取全局属性。

  * `ui/operators.py`: 更新现有的 `process_image` 调用。

  * `__init__.py`: 注册新类。

## 新增需求 (ADDED Requirements)

### 需求：独立的纸品生成

系统必须提供独立的 UI 和逻辑来生成纸制品。

#### 场景：生成矩形纸品（明信片/海报）

* **当** 用户选择一张图片并选择“矩形”模式时

* **则** 生成一个具有图片长宽比的平面网格。

* **并且** 将图片作为纹理应用。

* **并且** 应用极薄的厚度（默认 0.3mm）。

#### 场景：生成异形纸品（模切卡）

* **当** 用户选择一张图片并选择“异形”模式时

* **则** 追踪图片 Alpha 通道以创建切割形状（类似亚克力但无底座/插脚）。

* **并且** 将图片作为纹理应用。

#### 场景：纸品属性

* **当** 用户调整设置时

* **则** 他们可以控制：

  * **类型**: 矩形 / 异形

  * **尺寸**: 目标宽度/高度（矩形模式）或 缩放（异形模式）。

  * **厚度**: 纸张厚度（默认很小）。

## 修改需求 (MODIFIED Requirements)

### 需求：图像处理工具

**原因**: 为了在亚克力和纸品模块之间共享逻辑。
**迁移**: `process_image` 签名更改为接受 `offset`, `blur`, `threshold` 作为参数。
